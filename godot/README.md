# Godot-клієнт: перший екран «Гільдія»

- Версія: **Godot 4.7.2 stable**, звичайна версія з GDScript.
- Рендерер: **Compatibility**.
- Це лише тестовий новий клієнт, а не заміна чинного HTML-прототипу.

## Запуск

1. У Godot Project Manager натисни **Import** і вибери `godot/project.godot`.
2. Натисни **F5**. Відкриється екран «Гільдія».
3. Зміни ширину вікна. На вузькому екрані має бути двоколонкова сітка показників, вертикальне компонування панелей і кнопка меню.
4. Кнопка «Гільдія» залишає поточну сторінку відкритою. Кнопки ще не перенесених екранів повідомляють про обмеження, не імітуючи роботу функції. Економічні перемикачі лише демонстраційні.

## Web-експорт

Потрібні офіційні export templates відповідної версії Godot. В меню **Project → Export** вибери Web, за потреби налаштуй шаблони й експортуй у `godot/build/web/index.html`. Відкривай згенеровану Web-версію через HTTP-сервер, а не через `file://`.

Після експорту окремо перевір роботу на ПК і фізичному телефоні. Android APK на цьому етапі не збирався.

## Межі та дані

Усі числа, герої, репутація й процеси відтворюють **умовні дані** Web-прототипу і не є затвердженим балансом. Гравці, сервер, транзакції, бойова симуляція, збереження, інші екрани та Android-збірка не реалізовані. Чинний `index.html` залишається незміненим.
