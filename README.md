# Riskfate: The Living Guild

Фентезійна онлайн-RPG про управління гільдією автономних героїв і взаємопов'язаною економікою. **Цільова платформа — Android APK; поточні розробка і тести — через Web.**

## Вебпрототип
- [Відкрити інтерактивний UI-прототип](https://levian47.github.io/riskfate-the-living-guild/)
- Локальний запуск: відкрити `index.html` у сучасному браузері.
- Поточна реалізація — **демонстраційний інтерфейс без Android APK, серверної онлайн-гри та реального спільного ринку**. Умовні ресурси, герої, числа й дії не є затвердженим балансом.
- На сторінці героя, у вкладці «Вказівки», є **покроковий локальний стенд автономного циклу**: спершу потрібно встановити та зберегти обидва пороги для кожного з чотирьох ресурсів, далі відкрити «Автономний цикл героя» і натиснути «Запустити цикл». Стенд починає зі **100% кожного тестового ресурсу** (це не фактичний стан героя), переходить у полювання та реагує на ручні зміни ресурсів і кнопки тестового бою/втечі. Журнал фіксує рішення. Стенд не змінює збережений стан героя; бойові формули, реальні таймери, покупки й серверний автомат не реалізовані.
