# Riskfate: The Living Guild — план розробки

**Статус:** запропонований порядок робіт, не затверджений графік. Позначка виконання означатиме лише перевірений факт у **цьому** репозиторії.

## Етап 0 — фундамент проєкту

- [x] Створено окремий GitHub-репозиторій.
- [ ] Погодити початкову концепцію, правила роботи та межі першого прототипу з цього PR.
- [ ] Порівняти Godot 2D і Web UI саме для цієї гри; погодити платформу, рушій та спосіб тестування.
- [ ] Затвердити базовий спосіб керування гільдією й те, що герой вирішує самостійно.

## Етап 1 — автономний цикл (перший ігровий прототип)

**Пропонований обсяг:** 3 герої, просте місто та 2 локації з ворогами, без розширеної економіки.

- [ ] Стани героїв, пріоритети дій та відтворювана симуляція.
- [ ] Вихід у локацію, бій, HP/MP, відновлення, навик і витратний предмет.
- [ ] Критерії повернення, відпочинок і наступний вихід.
- [ ] Проста візуальна карта/панелі з поточними діями та причинами рішень.
- [ ] Базове збереження й завантаження стану.
- [ ] Перевірки повного циклу та крайових випадків.

**Приймання:** кілька героїв автономно проходять цикли без ручного керування; їхні дії та наслідки можна зрозуміти з UI; немає зависань у безвихідних станах.

## Етап 2 — гільдія та локальна економіка

- [ ] Завдання гільдії, їх виконання й одноразове нарахування нагород.
- [ ] Інвентар, здобич, ціни, купівля зіль/екіпірування, брак коштів/запасів.
- [ ] Роздільний облік ресурсів героя, гільдії та міських закладів.
- [ ] Керовані політики героїв (ризик, покупки, пріоритет завдань) — тільки після погодження.
- [ ] Перевірка, що автономна поведінка створює осмислений грошовий цикл.

## Етап 3 — розвиток міста

- [ ] Власники/статуси будівель та перші правила купівлі.
- [ ] Підприємства та їхній вплив на постачання героїв.
- [ ] Покупка додаткових територій, розширення впливу гільдії.
- [ ] Можливість повного контролю над містом — лише після перевірки балансу й корисності цієї мети.

## Етап 4 — системи прогресу й розширення

- [ ] Погодити, які саме рівні, ранги, характеристики, навики, майстерність та обмеження екіпу адаптуємо з 3D Pro.
- [ ] Розширити набір героїв, локацій, монстрів, спорядження й рішень AI.
- [ ] Опрацювати правила смерті, ризику й довгострокового розвитку.
- [ ] Тести продуктивності, збережень, балансу та тривалої симуляції.

## Принцип проходження етапів

Нове завдання — завершений перевірюваний результат, не нескінченний перелік дрібних правок. Не починати наступну велику систему, поки основний автономний цикл не працює та не прийнятий власником. Усі числові значення до балансувальних тестів вважати робочими.
